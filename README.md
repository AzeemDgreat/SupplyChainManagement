# SupplyChainManagement

Supply chain analytics and optimization projects: demand forecasting, routing, inventory and healthcare logistics.

## About this hub

This repository is an index. Each project lives in its own repository with its own code, tests, environment and results. The projects combine forecasting, optimization and simulation to support operational decisions, including pharma and cold-chain use cases.

## Projects

| Project | What it does | Stack | Status |
|---|---|---|---|
| retail-demand-forecasting | Statistical, machine learning and deep learning demand forecasts compared on public retail data | Python, statsmodels | Planned |
| last-mile-routing-optimization | Vehicle routing for a city delivery scenario | OR-Tools | Planned |
| inventory-safety-stock-optimization | Economic order quantity, reorder points and safety stock with Monte Carlo simulation | NumPy, SciPy | Planned |
| pharma-stockout-coldchain-analytics | Stock-out prediction and temperature excursion analysis for pharmaceutical supply | Python, scikit-learn | Planned |

## Standards across projects

- Automated tests and CI on every project
- Reproducible environment (requirements or environment file, Docker where it helps)
- Results reported from real runs, with the method and limitations stated
- Public datasets only, with sources and licenses cited
